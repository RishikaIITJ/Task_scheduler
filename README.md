## Overview

This project simulates two classic scheduling algorithms on real-world tasks and compares their performance:

| Algorithm | How it works |
|-----------|-------------|
| **FCFS** | Tasks execute in order of arrival (start time) |
| **Priority** | High priority tasks execute first, ties broken by start time |
